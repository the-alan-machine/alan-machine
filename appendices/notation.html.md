# Notation


Every symbol keeps the same meaning across the whole book.

| Symbol | Meaning | Unit |
|---|---|---|
| $k_B$ | Boltzmann constant | $\mathrm{J\,K^{-1}}$ |
| $T$ | Absolute temperature | $\mathrm{K}$ |
| $S$ | Entropy | $\mathrm{J\,K^{-1}}$ |
| $E$ | Energy | $\mathrm{J}$ |
| $\hbar$ | Reduced Planck constant, $h / 2\pi$ | $\mathrm{J\,s}$ |
| $c$ | Speed of light in vacuum | $\mathrm{m\,s^{-1}}$ |
